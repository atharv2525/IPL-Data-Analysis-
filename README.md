# IPL-Data-Analysis-
Data analysis project leveraging Excel and Python to explore IPL match data, uncover performance trends, and generate actionable insights through statistical analysis and visualizations.

# Overview
A data analysis project that explores IPL match data using Excel and Python to uncover team performance trends, venue impact, toss influence, and match-winning patterns. The project combines pivot table analysis, exploratory data analysis (EDA), and data visualization to generate actionable insights.

# Tools Used
- Python (Pandas, Matplotlib, NumPy)
- Excel
- Pivot Tables
- Jupyter Notebook

# Key Analysis Areas
- Team-wise winning performance
- Toss impact on match outcomes
- Batting vs Fielding decisions
- Venue-wise match distribution
- Win type analysis (Runs vs Wickets)
- Season-wise match trends

# Key Insights
- Mumbai Indians emerged as the most successful team, followed by Chennai Super Kings.
- Toss results showed minimal influence on overall match outcomes.
- Teams choosing to field after winning the toss had a clear preference over batting first.
- Matches won by wickets slightly exceeded matches won by runs, indicating the advantage of chasing.
- Home venues provided a noticeable advantage to teams due to familiar playing conditions.
- IPL has become more consistent in terms of the number of matches played per season.
